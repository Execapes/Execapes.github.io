### 汇编的基本语句
首先先声明一下，汇编主要分为两个阅读语法，一个是**amd64**语法，一个是**intel**语法，两种语法的阅读顺序不一致，例如：
```amd
mov %rdi , %rsi
```
他的意思代指rsi=rdi，而intel则相反，同样的效果写成：
```intel
mov rsi , rdi
```
以下讨论的（包括我学习的）都是intel语法。

接下来是基本语法部分
关于常量变量的定义：在 NASM 中，可以用 equ 定义汇编期常量。 例如，下面这段代码定义了一个名为UNIVERSE的常量，值为42：
```NASM
UNIVERSE equ 42
```
这个东西和其他语言基本上是完全不一样的，搞得我摸索了好久，实际上，汇编的常量和变量一般都是定义在文件顶部，在专用的模块里面定义的
equ定义的东西*没有地址、没有内存、没有任何运行时存在*，这一常量定义跟各变量不同，类似的还有%define（这个我不是很清楚）

变量和常量，放在不同的section下定义是不一样的，equ是一种没有内存的常量：
**section .data**下 —— 可读、可写。 放需要在运行时被修改的数据。可以在代码中往这下面定义的变量里写入新数据进行覆盖。

**section .rodata** —— 只读。 放永远不变的表和常量数据。被定义以后只会被“读”，从来没人写它们，所以 .rodata 是更严谨的位置。操作系统在内存页级别把这里标记为不可写，任何写操作直接崩溃，按ai一直说的就是——这是保护，不是麻烦。（真的很麻烦）

**section .bss** —— 可写，但不占文件体积。 放“只需要空间、不需要初始值”的变量（这块不是很熟悉）：
```GLM
section .bss
    result_buffer: resd 1    ; 预留 1 个 4 字节槽,内容初始为 0
```

接着就是通用寄存器了，这块最恶心

### 通用寄存器（GPRs）

在汇编中，我们通常不使用变量，而是用寄存器来存储值。 CPU 寄存器是计算机处理器内部的一块快速内存。 大多数计算都在 CPU 的寄存器中进行。
有些寄存器用于各种不同的计算，被称为通用寄存器（GPRs）。 另一些寄存器则有特殊或专门的用途。

在 x86-64 中，有 16 个 64 位通用寄存器（GPRs），它们也可以按 32 位、16 位或 8 位进行访问。 下面介绍了这些通用寄存器。

| 64 位 | 32 位 | 16 位 | 8 位 | 调用约定中的角色 | 调用后是否保留 |
| ---- | ---- | ---- | ---- | ---- | ---- |
| rax | eax | ax | al | 函数返回值；算术累加器(如 idiv 隐含使用) | caller-saved ❌ |
| rbx | ebx | bx | bl | 通用;常用于跨 call 保存值 | callee-saved ✅ |
| rcx | ecx | cx | cl | 第 4 个参数;循环计数(如 loop 隐含) | caller-saved ❌ |
| rdx | edx | dx | dl | 第 3 个参数；idiv 的余数、乘法高位 | caller-saved ❌ |
| rsi | esi | si | sil | 第 2 个参数；字符串操作源地址 | caller-saved ❌ |
| rdi | edi | di | dil | 第 1 个参数；字符串操作目的地址 | caller-saved ❌ |
| rbp | ebp | bp | bpl | 栈帧基址指针(简单代码可当通用寄存器) | callee-saved ✅ |
| rsp | esp | sp | spl | 栈顶指针(push/pop/call/ret 专用，别挪用) | callee-saved ✅ |
| r8 | r8d | r8w | r8b | 第 5 个参数 | caller-saved ❌ |
| r9 | r9d | r9w | r9b | 第 6 个参数 | caller-saved ❌ |
| r10 | r10d | r10w | r10b | 通用 | caller-saved ❌ |
| r11 | r11d | r11w | r11b | 通用 | caller-saved ❌ |
| r12 | r12d | r12w | r12b | 通用 | callee-saved ✅ |
| r13 | r13d | r13w | r13b | 通用 | callee-saved ✅ |
| r14 | r14d | r14w | r14b | 通用 | callee-saved ✅ |
| r15 | r15d | r15w | r15b | 通用 | callee-saved ✅ |

当使用少于 64 位时，访问的通常是寄存器中较低的那部分位。 这条规则的例外是ah、bh、ch和dh，它们访问的是寄存器 16 位部分中的高 8 位。

下面以rax寄存器为例，说明这些位是如何被访问的：
```NASM
+--------+---------------------------------------+
| 64-bit |                  rax                  |
+--------+-------------------+-------------------+
| 32-bit |                   |        eax        |
+--------+-------------------+---------+---------+
| 16-bit |                             |    ax   |
+--------+-----------------------------+----+----+
| 8-bit  |                             | ah | al |
+--------+-----------------------------+----+----+
```
其中一些寄存器在函数调用之间必须保持不变：rbp、rsp、rbx、r12、r13、r14和r15。 如果没有保持它们，可能会导致错误或未定义行为。

其余的寄存器不需要保持，可以自由使用：rax、rcx、rdx、rdi、rsi、r8、r9、r10和r11。

关于caller-save的含义（ai如是说）
- caller-saved(易失):`call` 一次，这些寄存器就可能被对方改掉。值放这里，call 前要么 push 保住,要么挪进*callee-saved*寄存器
- callee-saved(持久)：对方保证 call 前后不变，所以适合存需要跨函数调用的值。但轮到你自己写函数时，如果你改了它们，退出前要恢复原样。

### 函数
指令被组织成函数。 所有函数都放在源文件的section .text中。

一个函数声明由以下部分组成：

1. 一个带有函数名的标签，后面跟一个:。
2. 定义该函数的指令。
3. 返回指令ret
这个`ret`其实在内存上来说做了很多事情，`call` 调用一个函数时，CPU 会自动把“回来的地址”(call 的下一条指令位置)压到栈上；而 `ret` 就是把这个地址从栈顶弹出来，跳回去继续执行。`call` 和 `ret` 是一对，必须配对使用。

### 关于指令
x86-64 的指令有几百条，但日常写题真正用到的核心就几十条。~~但是每个都很烧脑~~
| 指令 | 作用 |
| ---- | ---- |
| `mov` | 复制数据(寄存器/内存/立即数之间) |
| `lea` | 算地址，不访存；也常用来做快速乘加运算 |
| `movzx` / `movsx` | 读取窄数据并零扩展/符号扩展到更宽寄存器 |
| `push` / `pop` | 压栈 / 出栈 |
| `xchg` | 交换两个操作数 |
算数运算如下：
| 指令 | 作用 |
| ---- | ---- |
| `add` / `sub` | 加 / 减，并设置标志位 |
| `inc` / `dec` | 加 1 / 减 1 |
| `neg` | 取负数 |
| `imul` | 有符号乘法(单操作数形式是隐含 rax 的全乘) |
| `idiv` / `div` | 有符号 / 无符号除法，商在 rax、余数在 rdx |
| `cqo` | 把 rax 符号位铺满 rdx,为 idiv 做准备 |
位运算（目前只用过xor）
| 指令 | 作用 |
| ---- | ---- |
| `and` / `or` / `xor` | 按位与/或/异或;`xor rax, rax` 是清零惯用法 |
| `not` | 按位取反 |
| `shl` / `shr` | 左移 / 逻辑右移 |
| `sar` | 算术右移(保留符号位) |
比较和跳转（条件判断和循环的原理）
依赖于标志符，这个蛮复杂的，会把cmp进行的结果存进ZF·CF等标志位里，代表cmp结果小于零或者大于零。cmp本质上是进行一个不保存结果数值的sub；
je，jne等j开头的jump命令是依赖cmp更改的标志位进行判断的
| 指令 | 作用 |
| ---- | ---- |
| `cmp` | 做减法只设标志位不存结果，是所有判断的前置 |
| `jmp` | 无条件跳转 |
| `je/jne`, `jg/jl`, `ja/jb` | 等于/不等于、有符号大于/小于、无符号大于/小于时跳 |
| `setcc` 系列 | 按条件把目标寄存器置 0 或 1 |
函数与栈
| 指令 | 作用 |
| ---- | ---- |
| `call` | 调用函数，压入返回地址 |
| `ret` | 弹出返回地址，回到调用者 |
| `leave` | 撤销栈帧(等价于 mov rsp,rbp + pop rbp) |
