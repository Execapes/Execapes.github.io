首先是开头 #include<stdio.h>
他可以说是 C 语言中最常见的一行代码，几乎每个 C 程序的开头都能看到它。
#include 是预处理指令，他算是能告诉编译器“请在这里引入/插入一个文件的内容”。
前面的 # 符号代表这是一个预处理指令。在程序真正开始编译成机器代码之前，预处理器会先执行这个指令，把指定的头文件内容完整地复制粘贴到你的代码开头，有点拗口，但是我个人理解是相当于告诉机器“我要开始写代码了”的感觉，可能<>里面会填不一样的东西。。。

然后是stdio.h ，gemini给我的解释是 标准输入输出头文件
stdio 是 Standard Input Output（标准输入输出）的缩写，.h 代表这是一个头文件（Header File）。我个人赶脚就是像GLSL里面开头要写的那个啥version声明，来进行一个非标准语言库的调用，这样才能用一些较为复杂的如scanf（“”）的命令。

关于条件判断
if语句用来条件判断，格式是if（条件）{条件为真时运行的代码}，感觉他干的事情和他长得很像（切勿把判断是否等于写成=，=基本上可以看为把等号后的东西赋值给前面的，==才是判断）
else可以说是if语句的附属代码，就跟英文原意一样，如果···那么就，他以下的是if条件成立以外情况发生是会运行的代码，一般可以用来写分支
switch适合多值等值判断，如以下代码
switch (grade) {
    case 'A':

        break; // 注意：break 用于跳出 switch
    case 'B':

它可以做到if不容易做到的多值判断，可以一次性判断很多条件（但是我基本没用过hehe）

然后是循环结构
for可以指定次数来运行代码，格式是for(最先运行的代码;跳出循环条件;附属代码运行完毕后一次循环中最后运行的代码){附属代码}，最套公式的常用用法是for(int i = 0;i < 想运行的次数; i++){代码代码代码}，第一次想原理的时候还想了蛮久的，感觉好牛逼
然后是while，这个我不怎么用，一般要用到while的地方for都能整好，但是还是说一下，while用法的格式是while(条件){代码（末尾代码是放在这里面的，而int i = 0 得在主代码里面先运行好）}，比较分散，个人不是很喜欢用
Gemini说它们之间最大的区别不在于“能不能做”，而在于“设计意图”与“适用场景”的不同；for是计数器驱动（已知循环次数/范围），更加集中式：初始化、条件判断、步进迭代写在一起，一般用在代码里比较明确的循环目的
而while代码是条件驱动（已知终止条件/状态），格式更加分散式：初始化在循环外，步进迭代在循环体内部，一般是用于条件未知和不定情况下

接着就是我感觉最难以理解的内存和指针了
数据都是存储在内存里的，而每个变量都有它对应的内存地址，就像门牌号一样，指针本质上也是一个变量，但是他装的是存储另一个变量的地址，就像一个命运共同体（bushi），一变两动
为毛要用这个东西？我当时也不太懂（到现在也不是很懂），但是我目前的个人理解最直观体现在写变量交换值的函数的那一题上；
如void swap_wrong(int x, int y) {
    int temp = x;
    x = y;
    y = temp;
}
这一串代码，真的扔到main里面运行实际上不会成功，为什么呢
假如我运行了int main() {
    int a = 5, b = 10;
    
    swap_wrong(a, b)
    printf("a = %d, b = %d\n", a, b);
最终printf的结果会发现a和b的值完全没有改变
原因是因为，当运行了函数，函数中的a和b传入后实际上并不是完整的进去再出来，而是被复制成了两份完全相同但独立个体，a被复制成了x，他们的值完全一样，就像双胞胎，但是这是两个人，你对第二个个体的改变不会影响第一个个体，而在函数里改变的实际上是你想改变的函数的双胞胎，原来的没变。
这个时候就必须得用上指针了，用指针来指向原来的变量，来做到真正把变量导入到函数中进行运行。
如代码 void swap_correct(int *px, int *py) {
    int temp = *px; // 暂存 px 指向的值
    *px = *py;      // 把 py 指向的值赋给 px 指向的位置
    *py = temp;     // 把 temp 赋给 py 指向的位置
}

int main() {
    int a = 5, b = 10;
    
    swap_correct(&a, &b); // 必须传入 a 和 b 的地址
    
    printf("a = %d, b = %d\n", a, b); // 输出: a = 10, b = 5 (交换成功)
    return 0;
}
这样才能真正把a导入，这个箭头就起到了作用。
